# CheckStartupAllDrives

CheckStartupAllDrives — это утилита на C#, которая проверяет состояние всех фиксированных дисков на компьютере и добавляет себя в автозагрузку Windows. Программа проверяет возможность записи на каждый диск и перезагружает компьютер, если обнаружены ошибки.

## Особенности

- Проверка прав администратора и перезапуск с правами администратора, если необходимо.
- Добавление в автозагрузку Windows.
- Проверка всех фиксированных дисков на наличие и возможность записи.
- Вывод информации о каждом диске, включая использованное и общее пространство.
- Перезагрузка компьютера при обнаружении ошибок на дисках.
- Обработка аргументов командной строки для удаления файла `disk.file` и вывода версии программы.

## Требования

- .NET 8 или выше
- Права администратора для запуска программы

## Установка

1. Скачайте исходный код или скомпилированный исполняемый файл.
2. Запустите программу с правами администратора.

## Использование

### Аргументы командной строки

- `-r` или `--reset`: Удаляет файл `disk.file`, если он существует.
- `-v` или `--version`: Выводит версию программы.

### Примеры

- Запуск программы с удалением файла `disk.file`:
  ```sh
  CheckStartupAllDrives.exe -r
  ```
- Запуск программы с выводом версии:
  ```sh
  CheckStartupAllDrives.exe -v
  ```
## Как это работает
1. Программа проверяет, запущена ли она с правами администратора. Если нет, она перезапускает себя с правами администратора.
2. Программа добавляет себя в автозагрузку Windows.
3. Программа получает список всех фиксированных дисков на компьютере.
4. Программа проверяет каждый диск на наличие и возможность записи, создавая и удаляя файл размером 100 МБ.
5. Программа выводит информацию о каждом диске, включая использованное и общее пространство, а также результат проверки.
6. Если на каком-либо диске обнаружены ошибки, программа перезагружает компьютер через 5 секунд.
7. Если все диски прошли проверку успешно, программа выводит сообщение об успешной проверке и ждет нажатия клавиши ENTER для завершения работы.
